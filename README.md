# Daeva Nexus

**O projeto foi refeito do zero.** Daeva Nexus é a nova base do aplicativo Windows para Aion 2.

## Primeira etapa

- Menu lateral com **Início**.
- Cartão do personagem com nome, classe, nível e retrato.
- Consulta ao perfil público da NCSoft para a América do Sul.
- Nova identidade visual e cabeçalho com saudação por horário.

A versão 0.1.0 é uma entrega inicial de desenvolvimento. A consulta ao perfil e ao retrato foi conferida, com 29 testes automatizados aprovados. A identificação automática após novo login ou troca de personagem ainda está em validação.

## Downloads e código-fonte

Os pacotes da nova base estão em [Daeva Nexus 0.1.0 alpha](https://github.com/skkarhub/Aion2Dps/releases/tag/v0.1.0-alpha.1).

- **DaevaNexus-Windows-x64-0.1.0.zip**: extraia a pasta completa e execute `DaevaNexus.exe`.
- **DaevaNexus-Source-0.1.0.zip**: projeto completo, testes e instruções de compilação.
- **SHA256SUMS.txt**: hashes dos arquivos distribuídos.

O código-fonte correspondente é distribuído no pacote **DaevaNexus-Source**, anexado à publicação.

Aplicativo independente, sem afiliação ou aprovação pela NCSoft.
